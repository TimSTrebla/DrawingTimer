Your own folder: how to organise it

Subfolders become categories; a folder named after a category (Anatomy, Hands, Pastel…; Dutch names work too) joins it. Put n1, n2 or n3 in a folder or file name to set the difficulty; without a label an image gets its category's default level. The images stay on your device.
